1. Visão Geral e Propósito

A aplicação "Ferramentas de Rede" é uma suíte profissional de software para desktop, desenvolvida em Python com a biblioteca CustomTkinter, projetada especificamente para administradores de sistemas e profissionais de TI que gerenciam ambientes baseados em Windows.

Versão Atual: 1.1.0
Linguagem Principal: Python 3.x
Interface: CustomTkinter (GUI moderna)
Foco: Gerenciamento de redes Windows e administração remota

Características Principais

  • Painel Centralizado: Interface unificada para múltiplas ferramentas de rede
  • Arquitetura Modular: Design escalável com separação clara de responsabilidades
  • Interface Moderna: GUI responsiva com temas claro/escuro
  • Multilíngue: Suporte completo para Português, Inglês e Espanhol
  • Segurança Avançada: Sistema de cofre de credenciais criptografado
  • Performance Otimizada: Carregamento sob demanda e processamento paralelo

2. Arquitetura da Aplicação

A aplicação segue uma arquitetura multicamadas bem definida, garantindo separação de responsabilidades, manutenibilidade e escalabilidade.

2.1 Camadas da Arquitetura

🎯 Ponto de Entrada (main.py)

  • Inicialização da aplicação com tela de carregamento
  • Configuração do sistema de logging
  • Carregamento da lista de hosts e verificação de status inicial
  • Tratamento de erros de importação e execução

🖥️ Camada de Interface (UI - app/ui_components/)

  • Navegação por Abas: Sistema dinâmico de abas criadas sob demanda
  • Fábrica de Ferramentas: tool_factory.py carrega funcionalidades quando necessário
  • Componentes Reutilizáveis: Dialogs, frames e widgets modulares
  • Gerenciamento de Estado: Indicadores de status e feedback visual

🎮 Camada de Controle (app_controller.py, tool_controllers/)

  • Controlador Principal: Orquestra ações de alto nível e gerenciamento de hosts
  • Controladores Especializados: Um controlador para cada ferramenta (Ping, Serviços, etc.)
  • Gerenciamento de Threads: Processamento assíncrono para operações de rede
  • Comunicação UI-Backend: Ponte entre interface e lógica de negócios

🔧 Camada de Backend (network_tools.py, system_tools.py)

  • Ferramentas de Rede: Ping, traceroute, descoberta de hosts, escaneamento de portas
  • Ferramentas de Sistema: WinRM, comandos remotos, gerenciamento de serviços
  • Comunicação Remota: Protocolos WinRM e PowerShell remoto
  • Processamento Paralelo: Otimizações para operações em lote

💾 Camada de Dados (host_manager.py, config.py)

  • Gerenciamento de Hosts: Persistência e carregamento de configurações
  • Configurações: Preferências de UI, constantes e parâmetros
  • Cache Inteligente: Armazenamento temporário para otimização
  • Logs e Monitoramento: Sistema de logging estruturado

6. Ferramentas de Rede

6.1 Classe NetworkTools (network_tools.py)

Funcionalidades Principais:

  • Verificação de Status: Ping otimizado com timeout configurável
  • Resolução DNS: Resolução de hostnames para IPs
  • Informações de Rede Local: Detecção automática de sub-rede
  • Descoberta de Hosts: Scanner de rede com processamento paralelo
  • Escaneamento de Portas: Verificação de portas comuns e personalizadas
  • Wake-on-LAN: Ativação remota de computadores

6.2 Descoberta de Hosts (discovery_scanner.py)

  • Scanner Local: Varredura da rede local automaticamente
  • Scanner Remoto: Usando um host como pivô
  • Scanner Personalizado: Faixa de IPs definida pelo usuário
  • Processamento Paralelo: Otimização para grandes redes
  • Cache Inteligente: Armazenamento de resultados para reutilização

6.3 Configurações de Rede

Portas Padrão:
  • TOP_60_PORTS - Portas mais comuns (20, 21, 22, 23, 25, 53, 80, 110, 135, 139, 143, 443, 445, 993, 995, 1433, 1723, 3306, 3389, 5900, 8080)
  • ALL_PORTS - Todas as portas TCP (1-65535)
  • Mapeamento de portas para nomes de serviços

  • Logs de Eventos: Consulta e filtragem de logs

8. Sistema de Segurança

8.1 Cofre de Credenciais (credential_service.py)

Características de Segurança:

  • Criptografia: Fernet (AES-128) com chaves derivadas
  • Derivação de Chave: PBKDF2 com 480.000 iterações
  • Salt: 32 bytes aleatórios por cofre
  • Proteção por Senha: Senha mestra obrigatória
  • Limite de Tentativas: Máximo 5 tentativas de desbloqueio
  • Backup Automático: Proteção contra corrupção de dados

8.2 Gerenciamento de Credenciais

Componentes de Segurança:
  • credential_service.py - Serviço principal de criptografia
  • credential_dialog.py - Interface de gerenciamento
  • credential_manager_dialog.py - Gerenciador avançado
  • vault_prompt_dialog.py - Prompt de desbloqueio
  • security_info_dialog.py - Informações de segurança

8.3 Funcionalidades de Segurança

  • Criação de Cofre: Geração automática de salt e chaves
  • Desbloqueio: Verificação de senha com derivação de chave
  • Armazenamento: Credenciais criptografadas por sessão
  • Recuperação: Sistema de backup e restauração
  • Limpeza: Remoção segura de dados sensíveis

10. Otimizações de Performance

10.1 Configurações de Performance (config.py)

Parâmetros Otimizados:
  • MAX_CONCURRENT_HOST_CHECKS = 20 - Verificações paralelas
  • HOST_CHECK_BATCH_SIZE = 20 - Tamanho do lote de processamento
  • HOST_CHECK_BATCH_DELAY = 0.05 - Delay entre lotes
  • UI_UPDATE_BATCH_DELAY = 0.02 - Atualizações de interface
  • MAX_WORKER_THREADS = 10 - Threads de trabalho
  • CACHE_CLEANUP_INTERVAL = 300 - Limpeza de cache (5 min)
  • MEMORY_MONITOR_INTERVAL = 600 - Monitoramento de memória (10 min)

10.2 Carregamento Sob Demanda

  • Fábrica de Ferramentas: Componentes carregados apenas quando necessário
  • Lazy Loading: Frames de ferramentas criados sob demanda
  • Cache Inteligente: Armazenamento de resultados para reutilização
  • Threading Otimizado: Processamento paralelo para operações de rede

10.3 Otimizações de Rede

  • Ping Otimizado: Timeout reduzido para carregamento rápido
  • Processamento em Lotes: Verificação de hosts em grupos
  • Conectividade Paralela: Múltiplas conexões simultâneas
  • Cache de DNS: Resolução de hostnames otimizada

10.4 Monitoramento de Recursos

  • Limpeza Automática: Remoção de dados temporários
  • Monitoramento de Memória: Controle de uso de recursos
  • Logs Otimizados: Nível INFO para reduzir overhead
  • Gerenciamento de Threads: Controle de threads ativas
